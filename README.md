### Hi, I'm Adriel 👋

Quantitative researcher and computational physicist (Dr. rer. nat., Materials Science) building AI-native tools for systematic trading.

**Now:** founder of [Torquant](https://torquant.app), an LLM-native platform that turns trading ideas written in plain language into executable, backtested crypto strategies.
- Event-driven and vectorized backtests with fees and slippage built in, forward tests, and robustness and stability tests
- Multi-asset strategies and portfolio construction
- Stack: Python backtest engine · FastAPI · React/TypeScript · LLM orchestration · Docker
- In development: LLM research agents that run 24/7, and self-custodial paper and live trading on Hyperliquid and Lighter with built-in live monitoring

The core Torquant codebase is private, so most of my activity here comes from it. The public piece is [torquant-plugin](https://github.com/adrielDom/torquant-plugin), which connects AI assistants to Torquant through MCP.

**Before:** independent quant research since 2023, covering concentrated-liquidity DeFi market making and delta-neutral funding-rate arbitrage.
